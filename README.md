# SkillCraft-Task-02-Data-Cleaning

SkillCraft Technology Internship Task 02: Data Cleaning and Preparation of Sales Forecasting Dataset using Python, Pandas, and Google Colab.


## Data Cleaning and Preparation

## Objective

The objective of this task was to clean and prepare a sales forecasting dataset for further analysis.

## Tools Used

 Python
 Pandas
 Google Colab

## Steps Performed

1. Loaded the dataset using Pandas.
2. Checked dataset structure and dimensions.
3. Identified missing values.
4. Checked for duplicate records.
5. Handled missing values in the Postal Code column.
6. Converted date columns into datetime format.
7. Exported the cleaned dataset.

## Dataset Information

 Total Rows: 9800
 Total Columns: 18
 Missing Values Found: 11
 Duplicate Records: 0

## Outcome

The dataset was successfully cleaned and prepared for further analysis and visualization.
